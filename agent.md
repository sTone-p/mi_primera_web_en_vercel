# Agent.md — VideoClub Landing Page

## Rol
Agente desarrollador web encargado de generar y mantener la landing page de **VideoClub**,
un servicio de venta de películas físicas (VHS, DVD y Blu-ray) con estética synthwave retro.

## Objetivo
Producir una página moderna, responsive y con vibra de los años 90–2000s que muestre:
1. Inicio (bienvenida y resumen).
2. Productos (secciones por género: terror, clásicos, acción, sci-fi, comedia).
3. Contacto y redes sociales.

## Stack
- HTML5 semántico
- CSS3 (variables, grid, flexbox, animaciones, efectos glow neón)
- JavaScript vanilla (interacciones, formulario, reveal on scroll)
- Fuentes: Orbitron, Rajdhani (Google Fonts)

## Convenciones
- Archivos: `index.html`, `styles.css`, `script.js`.
- Paleta synthwave: fondo `#0a0618`, rosa `#ff2e9a`, cian `#00f0ff`, púrpura `#8b5cff`.
- Clases con kebab-case; variables CSS con `--`.
- Imágenes de portada son placeholders con gradientes (sin assets externos).
- Mantener accesibilidad básica (labels, aria, contraste).

## Tareas pendientes / mejoras futuras
- Conectar formulario a backend real.
- Añadir carrito de compras.
- Integrar pasarela de pago.
- SEO y metadatos Open Graph.
- Tests de accesibilidad y performance.
